# Family Fables – Releases

Fertige Versionen der Family-Fables-App (Android). Die App holt sich Updates automatisch von hier
(`releases/latest/download/update.json`).

**Neueste Version installieren:** unter [Releases](../../releases/latest) die Datei `familyfables-x.y.z.apk`
auf dem Handy herunterladen und öffnen.

**Was ist neu?** → [Änderungsliste (CHANGELOG.md)](CHANGELOG.md)
